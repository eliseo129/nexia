# Nexia — Landing de agentes de IA

Landing estática (HTML + CSS + un JS mínimo). Sin build ni dependencias.

## Ver en local

    python3 -m http.server 8000

Abrir http://localhost:8000

## Archivos

- `index.html` — todas las secciones (hero, agentes, proceso, planes, FAQ, CTA)
- `styles.css` — estilos y tema (variables en `:root`)
- `script.js` — envío del formulario de demo (hoy solo muestra confirmación)
- `favicon.svg`, `robots.txt`

## Pendiente

- Conectar `#demo-form` a un backend o servicio de formularios.
- Cambiar marca, textos y precios reales.
